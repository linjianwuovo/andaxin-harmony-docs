# 安大信（鸿蒙端）隐私政策

更新日期：2026-11-22
生效日期：2026-11-22

安大信（下称"本应用"）是一款面向安徽信息工程学院学生的校园信息客户端，由个人开发者黄铮辉独立开发。本应用不是安徽信息工程学院的官方产品，与学校没有隶属关系，也未获得学校官方授权。

本政策说明本应用如何处理你的个人信息。**本应用没有自己的服务器，不建立账号体系，也不收集你的数据做画像、广告或统计。** 你的校园数据由学校系统及学校采用的第三方教学、校园卡平台直接返回，显示在你的手机上。

## 一、谁处理你的信息

- 个人信息处理者：黄铮辉（个人开发者）。
- 联系邮箱：linjianwuovo@icloud.com
- 问题反馈：https://github.com/linjianwuovo/andaxin/issues
- 你的校园账号、校园卡、课程与成绩等数据由安徽信息工程学院及其采用的平台管理和保存。学校系统内数据的处理规则，以学校的规定和隐私政策为准。

## 二、本应用处理哪些信息

### 1. 校园账号、口令与会话

- 学号：用于向学校系统登录，以及在你退出登录后预填账号。
- 口令：只在你勾选"记住密码"并成功登录后，通过系统提供的加密存储（Asset Store）保存在本机；不勾选则不保存。
- 会话令牌：登录后，学校系统、AI 课堂平台、校园卡平台分别返回的会话令牌或 Cookie 保存在应用私有目录，用于免重复登录。
- 这些凭据不会发送给开发者，也不会上传到开发者控制的服务器。口令在你登录时由学校公钥加密后直接提交给学校系统。

### 2. 学校业务数据

课表、成绩、待办与审批、公告与消息、校园卡余额与流水、查寝任务、运动记录、AI 课堂与公开课等，均由学校系统或学校采用的对应平台返回。本应用只在内存中展示这些内容，不把业务内容写入开发者服务器。播放进度、课表配色、上次停留页面等偏好保存在本机。

### 3. 位置信息

- 查寝签到：在你点击"定位"并授权后读取一次当前位置，转换为 BD-09 坐标，随签到请求提交给学校系统。
- 跑步记录：在你主动开始一场跑步后，应用会在运动期间约每 3 秒或每移动 5 米读取一次位置，用于计算里程和轨迹；你结束并确认提交时，轨迹会转换为 BD-09 坐标并上传给学校运动系统。
- 我们不在其他功能中读取位置，不做后台定位，也不把位置历史写入本机；跑步轨迹只在你主动开始的一场中采集，并随提交发送给学校。位置不用于广告或画像。可在系统设置中关闭定位权限；关闭后查寝签到和跑步轨迹不可用，其他功能不受影响。

### 4. 相机与照片

- 查寝签到：你主动点击"拍一张 / 相册"时，通过系统相机或系统相册选择 1 张照片；照片只在你确认提交签到请求时上传给学校系统。
- 报修：你主动点击"照片"时，通过系统相册选择照片，最多 10 张；选图和移除照片只修改当前草稿。你确认提交报修、表单及登录状态校验通过后，应用才逐张上传仍选中的照片，并把照片编号随报修单发送给学校报修系统。上传或报修单提交失败后不会自动重试；你可以确认后重试，当前草稿会复用已上传照片的编号。已上传到学校的照片由学校服务管理，移除本机草稿中的照片不会撤销已完成的上传。
- 本机头像：你在个人资料页主动选择头像后，应用读取该照片并在应用私有目录按校园账号保存压缩副本，用于下次打开时显示。头像只保存在本机，不上传到学校或开发者服务器；不同账号的头像分别显示。更换头像会替换该账号旧头像；在"我的"中撤回隐私同意时会清除全部账号的本机头像。
- 本应用不申请常驻的相机、相册权限，拍照和选图由系统组件完成；只读取你主动选择的照片。查寝和报修照片不会由本应用长期保存副本；本机头像按上述说明保存。

### 5. 日历与日程

- 只有你在课表点"导入整学期到日程"时，应用会请求日历读写权限，从本周起逐周向学校取真实课表，把课程名、教室和起止时间写入系统日历。
- 应用只写你主动导入的课程，不读取你的其他日程，也不上传日历内容；写入的记录可在系统日历里自行删除。

### 6. 本机保存的数据与期限

- 学号、登录会话令牌、AI 课堂令牌与 Cookie、校园卡令牌、课表配色、上次停留页面、播放进度、导入日程的事件 ID。
- 勾选"记住密码"后保存的加密口令。
- 主动检查更新成功后保存的鸿蒙公开版本信息与检查时间，不含学校账号、会话令牌或设备标识；撤回隐私同意、清除应用数据或卸载时删除。
- 按校园账号保存的本机头像压缩副本。退出登录后不再显示该会话的头像；头像副本会保留到更换、撤回隐私同意或卸载应用。撤回时如清理失败，应用会提示重试，不会宣称已经清理完成。
- 以上数据保存在应用私有目录或 Asset Store 中，只有本应用可读；保存到你清除、退出登录（仅会话）或卸载应用为止。学校系统内的数据保存期限由学校决定。
- 本应用发布版不写本地调试日志。

### 7. 本应用不收集

通讯录、短信、通话记录、剪贴板、IMEI/OAID 等设备标识、应用安装列表；不做后台持续定位，也不把位置历史写入本机文件（跑步轨迹只在你主动开始的一场中采集，随提交发送）。不集成广告、统计、推送 SDK。

### 8. 主动检查应用更新

- 只有你在“我的—关于”点击“检查更新”时，应用才会通过 HTTPS 请求官方 GitHub Pages 上的鸿蒙版本文件（linjianwuovo.github.io/andaxin-harmony-docs/site/harmony-update.json），不会在启动或后台自动检查。
- 该请求不携带学校账号、学号、姓名、学校或 AI 课堂令牌、Cookie、设备标识或 GitHub 访问令牌。GitHub Pages 会记录访问所需的 IP 地址用于安全目的，固定请求头包含 Accept 与 User-Agent；详见 [GitHub Pages 数据收集说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。
- 应用只缓存校验成功的公开版本信息与检查时间；失败时保留上次结果并说明检查失败，不把缓存当作刚确认的最新状态。
- 只有你主动打开发布记录或安装包链接时，才会唤起系统浏览器访问 GitHub（github.com）。安装包仓库仍为私有，下载需要你自己的仓库访问权限；GitHub 登录由浏览器和 GitHub 处理，本应用不读取或代填凭据，不自动安装。

## 三、信息如何提供与共享

本应用不含第三方 SDK；除以下必要场景外，不向第三方提供你的信息，也不出售你的个人信息：

- 学校各业务系统（*.aiit.edu.cn）：登录、课表、成绩、待办、公告、查寝、报修、请假、运动等。用于完成你主动使用的功能。
- AI 课堂、公开课（fifedu.com）：使用这些功能时，本应用会把学校登录令牌、学号、姓名、用户类型发送给该平台，用于单点登录和读取课程数据。
- 校园卡（17wanxiao.com）：使用校园卡功能时，本应用会把学校登录令牌、学号、姓名、用户类型发送给该平台，用于换取校园卡会话、查询余额与流水；只有你主动点击“打开校园卡交易页”时，才会将这些身份参数交给经校验的新开普 HTTPS 网页入口。
- 校园卡网页使用临时浏览模式，网页中的业务操作由你在第三方页面自行确认，本应用不自动发起充值、挂失或其他交易。退出该网页、切换账号或退出登录时，会清空该网页及临时模式的 Cookie；无法清理临时 Cookie 时，不加载带身份的校园卡网页。普通学校网页与 AI 课堂的 Cookie 不因该清理受到影响。
- 报修照片：在你确认提交报修后，上传到学校报修文件服务（repair.aiit.edu.cn）。
- 应用更新（GitHub Pages / GitHub）：主动检查时提供连接所需的 IP 地址及固定基础请求头；打开发布记录或安装包时由系统浏览器访问 GitHub。不会向更新通道提供学校身份、会话或设备标识。

上述学校业务平台由学校采用，GitHub 是开发者选用的更新托管服务；这些服务自身也会按其隐私政策处理数据；如果你不同意，请不要使用对应功能。法律法规要求或有权机关依法调取时，开发者会依法配合；由于开发者不持有你的数据，此类请求通常会直接指向学校或相应平台。

## 四、存储与安全

- 本应用没有后台数据库；本机数据存放在应用私有目录，其他应用无法读取。口令保存在系统 Asset Store。
- 与学校、平台之间的请求使用 HTTPS。**校内运动系统目前只提供 HTTP 接口**，使用跑步提交时，跑步数据（含学号、姓名、轨迹）会以未加密方式在该校内地址传输。请避免在不可信网络下使用跑步提交；开发者会向学校反馈升级 HTTPS。
- 学校站点使用系统证书校验。若校方网关证书异常，应用会提示连接失败，不会静默忽略证书错误。
- 主动更新检查连接 GitHub Pages，主动打开更新链接由系统浏览器访问 GitHub，相关 IP 地址与基础请求信息由该服务处理，可能涉及境外服务；本应用不会向更新通道提供学校身份、会话或设备标识。

## 五、你的权利

- **查看与更正**：个人信息页展示学校返回的资料；如有错误，请向学校系统更正。
- **删除本机数据**：在"我的 → 关于"退出登录会清除学校、AI 课堂、校园卡会话；在登录页点"重填"会删除已保存口令；清除应用数据或卸载应用会删除全部本机数据。学号会在退出登录后保留，用于下次预填，可在登录页直接改掉。
- **撤回同意**：在"我的 → 关于"选择"撤回隐私同意"，应用会清除本机会话与已保存口令并回到隐私告知页；也可在系统设置中关闭定位权限。
- 本应用不在服务器留存数据，因此没有需要向开发者申请删除的云端数据。学校系统内的数据请向学校申请。
- 我们会在核实身份后 15 个工作日内答复你的隐私问题。

## 六、未成年人

本应用面向在校大学生，不面向 14 周岁以下儿童。若你未满 18 周岁，请在监护人指导下使用，并由监护人阅读本政策。

## 七、政策变更

本政策更新会在本页面标注日期。涉及处理目的、信息类型或共享对象的重大变更，我们会重新征得你的同意，而不是仅以继续使用视为接受。
